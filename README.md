# TaskFlow - Beautiful Task Management Application

A stunning, modern to-do application built with vanilla HTML, CSS, and JavaScript. TaskFlow helps you stay organized, motivated, and productive with a beautiful interface and powerful task management features.

## Features

### ✨ Core Features
- **Add & Maintain Tasks** - Create tasks easily with an intuitive interface
- **Multiple Lists** - Organize your tasks into different categories (Work, Personal, Shopping, etc.)
- **Mark Complete** - Celebrate your achievements with completion checkmarks and celebration animations
- **Edit Tasks** - Modify task details including title, description, date, and time
- **Set Date & Time** - Schedule tasks with specific dates and times
- **Delete Tasks** - Remove tasks you no longer need

### 🎨 User Experience
- **Beautiful Design** - Modern gradient interface with smooth animations
- **Real-time Stats** - Track total tasks, completed tasks, and progress percentage
- **Smart Filtering** - View All, Pending, or Completed tasks
- **Motivational Quotes** - Get inspired with rotating motivational messages
- **Celebration Effects** - Enjoy confetti animations when you complete tasks
- **Overdue Detection** - Visual indicators for overdue and today's tasks
- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices

### 💾 Data Management
- **Local Storage** - All tasks and lists are automatically saved to your browser
- **No Account Needed** - Everything stays on your device, no cloud required
- **Persistent Data** - Your tasks remain even after closing and reopening the app

## Getting Started

### Installation
1. Download the `index.html` file
2. Open it with your web browser (Chrome, Firefox, Safari, Edge, etc.)
3. That's it! No installation or dependencies needed

### Usage

#### Adding a Task
1. Type your task in the input field at the top
2. Click "Add Task" or press Enter
3. Your task appears in the list

#### Creating a List
1. Click the "+ New List" button in the sidebar
2. Enter your list name (e.g., "Work", "Personal", "Shopping")
3. Click "Create List"

#### Managing Tasks
- **Complete a Task** - Click the checkbox next to a task
- **Edit a Task** - Click the edit (✏️) button on a task card
- **Delete a Task** - Click the delete (🗑️) button on a task card
- **Set Date & Time** - Edit a task and use the date and time fields

#### Filtering Tasks
- **All** - View all tasks in the current list
- **Pending** - View only incomplete tasks
- **Completed** - View only completed tasks

#### Managing Lists
- **Switch Lists** - Click on any list name in the sidebar
- **View Stats** - See completion count next to each list name
- **Delete a List** - Hover over a list and click the × button (must have at least one list)

- ✓ Your data stays private and on your device

## Browser Storage Note

All data is stored in your browser's local storage. Here's what you should know:

- **Location:** Browser-specific (each browser has its own storage)
- **Capacity:** Usually 5-10MB per domain
- **Persistence:** Data remains until you clear browser cache
- **Privacy:** Data never leaves your computer

## Troubleshooting

### Tasks disappeared
If your tasks have disappeared, try:
1. Check you're using the same browser
2. Check if cookies/cache were cleared
3. Refresh the page (Ctrl+R or Cmd+R)

### Modal won't close
- Click outside the modal to close it
- Click the Cancel button

### Can't add tasks
- Ensure you're not in a closed or deleted list
- Try refreshing the page
